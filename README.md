我的人工智能记忆档案｜中文总目录

一、建立档案的目的

我建立这套档案，是希望不同的人工智能工具能够逐步了解我的思想、人生经历、兴趣爱好、投资理念、创作项目和长期目标。

我希望人工智能成为长期的学习伙伴、思考助手和创作合作者，而不只是回答临时问题的工具。

二、五份核心档案

01｜个性与思考习惯

[01｜个性与思考习惯](personality.md)

记录我的性格特点、独立思考方式、判断原则，以及我希望人工智能如何与我交流。

02｜兴趣爱好与学习目标

[02｜兴趣爱好与学习目标](interests.md)
记录我的学习兴趣、知识探索方向、英语学习目标及长期学习计划。

03｜投资理念与长期规划

[03｜投资理念与长期规划](investment.md)


记录我的投资原则、风险意识、资产配置研究方向和长期投资目标。

不记录银行账号、证券账号、密码、验证码及其他敏感金融信息。

04｜人生经历与创作项目

[04｜创作项目与长期计划](projects.md)

记录我的人生经历、自传创作方向、视频制作项目，以及未来希望完成的作品。

创作坚持真实、不粉饰，注重独立观察与个人思考。

05｜人工智能协作原则

[05｜人工智能使用说明](AI-instructions.md)

记录我希望人工智能遵循的交流方式、分析标准、记忆整理方法和长期协作原则。

人工智能应尊重事实、指出错误、解释原因，不盲目迎合我的判断。

三、人工智能使用说明

1. 优先阅读本总目录，再根据问题查阅相关档案。
2. 尊重我的独立思考，不将个人观点当作事实。
3. 对不确定的信息明确说明，不编造事实。
4. 对重要问题提供依据、风险分析和不同角度。
5. 尽量使用中文交流，解释清楚，避免不必要的重复。
6. 记录长期目标时，应区分已经完成、正在进行和未来计划。
7. 不主动要求或保存密码、验证码、完整账号等敏感资料。
8. 档案内容可能随时间变化，重要信息应核对更新日期。

四、长期维护原则

这套档案不是一次性完成的，而是随着我的学习、生活、投资和创作不断更新。

新增内容应归入对应档案，避免重复和混乱。

重要决定应记录日期，已经改变的计划应及时修订。

五、最终目标

建立一套由我自己掌握、可以长期保存、持续更新、方便不同人工智能工具读取的个人知识与记忆体系。

让人工智能更了解我的过去，理解我的现在，协助我探索未来。
